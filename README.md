# 米哈游养成记录 (mihoyo-tracker)

记录《原神》《崩坏：星穹铁道》《绝区零》三个游戏的养成进度：角色、武器 / 音擎、遗器、星魂 / 命座 / 影画。本地存档，离线可查。

> 本仓库与发行包**不含任何游戏官方美术素材**，也**不含素材抓取脚本**。

## 功能

- 三个游戏分标签页，各 4 支队伍
- 每个角色记录：等级、星魂 / 命座 / 影画、当前与目标、毕业状态、专武、遗器
- 队伍备注、词条统计、毕业与遗器进度汇总
- 本地 JSON 存档，纯离线，不上传任何数据

## 素材说明（重要）

程序**不附带**角色立绘、命座 / 星魂图案、遗器与武器图标。

素材缺失时程序会自动降级：头像位置显示角色名首字方块（如「叶」「金」「水」），其余功能完全正常，不影响记录与统计。

如果希望显示官方图标，请自行准备图片，放到程序目录下的 `assets_wiki/` 中，目录结构如下：

```
assets_wiki/
├── characters/<game>/<角色名>.png
├── constellations/<game>/<角色名>_<序号>.png
├── weapons/<game>/<武器名>.png
└── relics/<game>/<遗器名>.png
```

`<game>` 取以下三个值：

| 值 | 对应游戏 |
|---|---|
| `genshin` | 原神 |
| `hsr` | 崩坏：星穹铁道 |
| `zzz` | 绝区零 |

文件名与游戏内中文名一致，例如 `assets_wiki/characters/hsr/三月七.png`。

素材请自行从官方渠道，或自己合法获取的途径准备。本仓库不提供下载源，也不对第三方素材的版权负责。素材版权归米哈游（miHoYo / HoYoverse）所有，仅供个人本地使用，请勿再分发。

## 存档结构

```json
{
  "version": 1,
  "games": {
    "<game_key>": { "teams": [], "roles": [], "weapons": [] }
  }
}
```

空结构样例见 `records.example.json`。程序首次运行会在自身目录生成 `records.json`。
